# Как получить `api_id` и `api_hash`

VoiceDrop общается с Telegram через **твои собственные ключи приложения**. Они
бесплатные, делаются за минуту и не имеют отношения к паролю от аккаунта.

> **Зачем они нужны?** Telegram требует, чтобы любой сторонний клиент был
> зарегистрирован как «приложение». `api_id` и `api_hash` — это его
> идентификатор. Пароль от аккаунта вводится позже, при входе.

## Шаги

1. Открой <https://my.telegram.org> и войди по номеру телефона.
   Код придёт в Telegram. Номер должен быть тем, с которого собираешься
   отправлять файлы.
2. Зайди в **API development tools**.
3. Если приложения ещё нет, заполни короткую форму:
   - **App title** — любое, например `VoiceDrop`
   - **Short name** — строчными, например `voicedrop`
   - **URL** — можно оставить пустым
   - **Platform** — выбери *Desktop*
   - **Description** — любое, например `personal file sender`
4. Нажми **Create application**.
5. На странице появятся **App api_id** (число) и **App api_hash** (32
   hex-символа). Скопируй оба.

## Куда их вставить

1. Запусти VoiceDrop. На чистой установке панель **API & runtime** откроется
   сама.
2. Вставь `api_id` и `api_hash`, нажми **Save**.
3. Появится окно входа: номер телефона, код из Telegram и пароль 2FA, если он
   включён.

Всё хранится только на твоей машине, в `data/config.json` рядом с exe (или в
пользовательской папке данных, если папка приложения недоступна для записи).

## Если что-то не так

| Сообщение | Что значит |
|---|---|
| `API_ID_INVALID` | неверный `api_id` или скопирован с пробелами |
| `API_ID_PUBLISHED_FLOOD` | эту пару ключей уже публиковали; создай новое приложение |
| `PHONE_NUMBER_INVALID` | номер нужен с кодом страны, например `+380…` |
| `PHONE_CODE_INVALID` / `PHONE_CODE_EXPIRED` | запроси новый код и введи быстро |
| `SESSION_PASSWORD_NEEDED` | у аккаунта включена 2FA — введи пароль на следующем шаге |

## Безопасность

- `api_hash` — это секрет. Не коммить его, не вставляй в публичные issues и не
  показывай скриншоты панели настроек.
- Одной пары на человека достаточно; позже можно создать вторую.
- Отозвать: на my.telegram.org → **API development tools** → **Delete
  application**. Уже открытые сессии продолжат работать, пока не выйдешь из них
  в Telegram → Настройки → Устройства.
